    Profiles

    Each profile has its own logins, cookies and extensions. Click a name to rename it and the dot to change its color. Right-click a profile to make it the default, for links from other apps and for new tabs when nothing else decides, or to delete it.

    Keep on top

    Threads you've opened within this time sit at the top of the sidebar. Older ones move to Earlier at the bottom.

    Archiving

    Summarize
    Archive

    Threads you haven't opened for a while first unload their pages and shrink to one line: how many tabs, which sites, how long ago. Opening one loads it again. Later they close and leave the sidebar. Type in the address bar to find and reopen them. Kept threads never archive, and a folder in Kept can catch threads by address before they do: right-click the folder and choose Auto-file rules.

    Apps

    ⌥⇧Space shows only the threads of the app you were in, and the sidebar groups each app's threads under its name. Pick the profile an app's new tabs open in; Auto uses the tab you were on. Right-click an app to link it with another, so they share one set of threads.

    Restyling

    The wand in the toolbar opens restyling in the sidebar: describe how the site you're on should look, and the agent writes a stylesheet that applies to every page of that site. It runs through Claude Code or Codex with your subscription, so the claude or codex command must be installed and signed in. Each request sends a screenshot of the page and an outline of its layout and text.

    Addresses that contain one of these show as Private in the address bar and the tab list until you click the address bar. One per line; * matches anything, so *.corp.example covers every site under corp.example.
