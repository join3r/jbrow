After

Threads you haven't opened for this long close and leave the sidebar. Type in the address bar to find and reopen them. Kept threads never archive, and a folder in Kept can catch threads by address before they do: right-click the folder and choose Auto-file rules.

Private addresses

Addresses that contain one of these show as Private in the address bar and the tab list until you click the address bar. One per line; * matches anything, so *.corp.example covers every site under corp.example.

Screen sharing

Extension shortcuts

Keys that run an extension's commands while jbrow is open, for the profile of the tab you're on. Click a shortcut and press the new keys; Delete removes it, Esc keeps the old one.

Hotkeys, profiles and linked apps are in ; those need a restart.
